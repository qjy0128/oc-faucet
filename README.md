# OC Faucet

把 OpenCode 免费模型的编程能力接入你手头的 AI 编程工具——ZCode、Claude Code、Codex、Kimi Code、Pi、DSH、qoder、WorkBuddy、CodeBuddy 等十种客户端，装上就能像用原生模型一样用它们。

免费模型「只会聊天、不会干活」的居多。OC Faucet 在中间做三层事：**逐个体检**（真发请求，筛出能按协议产生工具调用的模型）、**协议翻译**（Anthropic / OpenAI / Responses 三种方言互转）、**信封约束**（模型只许「提议」动作，真正执行永远在你自己的客户端手里，越权调用直接拦截或转交）。

## 下载安装

到 [Releases](../../releases) 页面下载对应平台的安装包：

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `OC.Faucet-1.0.1-arm64.dmg` | 打开拖进「应用程序」 |
| Windows（64 位） | `OC.Faucet-Setup-1.0.1.exe` | 双击安装 |

也可以从源码跑（需要 Node.js ≥ 22 和本机装有 [OpenCode](https://opencode.ai)）。内嵌模式支持 OpenCode 1.x 和 2.x，启动时会自动识别主版本并选择对应的启动参数与 API：

```bash
npm install
npm run desktop   # 桌面面板
npm start         # 或只跑后台服务
```

## 使用方式

启动后面板自动完成「拉目录 → 体检」，跟着界面从上到下走一遍即可：

1. **读取模型目录**：拉取免费池清单，只留价格全为 0 的模型；
2. **检测全部**：逐个真发请求体检（消耗少量免费额度），结论缓存 6 小时；失败的模型每 10 分钟自动重测，免费池几分钟一换，挂掉的模型随时可能翻案；
3. **一键接入**：在目标区点「写入」，把体检通过的模型写进对应工具的配置，重启该工具后模型出现在选择列表；「移除」只摘 OC Faucet 自己写的条目；
4. 右下角状态栏：复制**转发口地址**和**密钥**、重启/关闭服务。

给不支持自动写入的客户端手动接入时，三件套：Base URL `http://127.0.0.1:41982`（OpenAI 兼容客户端加 `/v1`）、API Key 用面板上的密钥、模型 ID 用模型清单里的 id。

## 两种上游方案

右下角「方案」随时可切，端口、密钥、已写入的配置都不动：

- **内嵌**（默认）：在你电脑上养一只隔离的 OpenCode 做推理——独立目录、环境变量白名单、不带任何你自己的凭据；
- **伪装**：直连 OpenCode Zen 免费池，请求逐字节模仿 OpenCode 客户端，完全不依赖本地 OpenCode（内嵌路线被卡死时的保底）。

两方案的体检结论分开记忆，来回切换不用重测。

排障时可把环境变量 `OCF_ISOLATE` 设为 `0` 临时关闭内嵌隔离。此时会复用你本机 OpenCode 的配置和凭据，可能使用付费供应商并产生费用；仅限确认风险后临时排查，完成后删除该变量或改回 `1`。

## 局域网访问

打开右下角「路由器广播」，同一 Wi-Fi 下的手机、另一台电脑也能接入（端口、密钥不变；关掉立即恢复只听本机）。开着时点「局域网配置」可查看接入地址、密钥和教程。浏览器网页始终进不来，局域网设备必须带密钥。

## 模型上下文与推理档位

模型详情里可以单独设置上下文长度（伪装模式下不支持），也可以看到每个模型支持的推理档位；客户端选择的档位会真正传给上游，不支持时明确报错而不是悄悄降级。

## 常见问题

- **体检失败的模型能用吗？** 多半是「那一刻」免费池路由不到，失败结论只缓存 10 分钟，之后自动重测；持续失败就是真不可用。
- **模型乱调工具怎么办？** 不会发生。本机动作全部被审批闸拦下：能翻译成你客户端工具的就「转交」当答案，翻不了就带着原因拒批，模型退回文字作答。
- **会花我的钱吗？** 不会。只放行价格全为 0 的官方免费模型，任何用户凭据都不进入上游。
